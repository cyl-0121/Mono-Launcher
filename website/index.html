下载说明

主下载（本站） 上面的按钮指向本站服务器，国内直连速度更快。
备用下载（GitHub） 主站不可用时，可到 GitHub Releases 下载同一文件。
免安装 解压后双击 MonoLauncher.exe 即可，不需安装 .NET。
数据目录 存档与配置保存在 %APPDATA%\MonoLauncher，删程序不丢实例。

版本与加载器正式版 / 测试版 / 愚人节版分类，Fabric / Quilt / NeoForge / Forge 一键安装
