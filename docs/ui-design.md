# 界面设计

## 设计目标

- 参照 PCL2 的页面结构：左侧竖排导航 + 右侧内容区 + 顶部自定义标题栏。
- 融入 Minecraft 元素：石质深灰背景、像素网格、草绿主色、方块图标。
- 不使用 WebView / HTML / CSS。
- 窗口无系统边框，标题栏完全自绘（Windows 上不会出现白色标题栏）。

## 布局

```
┌──────────────────────────────────────────────────────────┐
│ [方块图标] GlassCraft v0.9            —   □   ✕          │  34px 自绘标题栏
├──────────┬───────────────────────────────────────────────┤
│ 🏠 主页   │  页面标题            副标题      [账户：xxx]   │  44px
│ ⬇ 下载    │                                               │
│ ▦ 版本列表│                                               │
│ 🧩 Mod    │              页面内容（卡片）                  │
│ 🌐 联机   │                                               │
│ ⇩ 下载管理│                                               │
│ 📄 日志   │                                               │
│ ✦ AI 助手 │                                               │
│ ⚙ 设置    │                                               │
│           │                                               │
│ 标准 / FPS│                                               │
└──────────┴───────────────────────────────────────────────┘
```

- 导航宽 188px，选中项左侧高亮（草绿文字 + 深色背景）。
- 标题栏 34px：拖动移动、双击最大化、三个窗口按钮。
- 内容区外边距 16px，页面之间用 12px 间距。

## Minecraft 元素

- **方块图标**：标题栏左侧一个 20×20 的方块，顶部 7px 草绿、下方土棕，模拟草方块。
- **像素网格背景**：`AuroraBackground` 用 Skia 绘制 16px 网格与随机明暗块，顶部叠加草绿光晕，边缘暗角。
- **像素化按钮**：1px 边框、3px 圆角、按下/悬停变色，接近 MC 按钮观感。
- **卡片刻度**：4px 圆角、1px 边框、顶部高光与底部阴影（按档位裁剪）。

## 界面效果档位

| 档位 | 效果 |
|---|---|
| 完整 | 卡片阴影 + 顶部高光 |
| 标准（默认） | 卡片阴影 |
| 简洁 | 仅填充与边框 |
| 关闭 | 不绘制卡片背景（纯色窗口） |

切换即时生效，不需要重启。

## 窗口行为

- `SystemDecorations="None"`，标题栏自绘。
- 拖动：按住标题栏；双击：最大化/还原。
- 最大化由 Avalonia 处理工作区，不覆盖任务栏（实测 rect 0,0–1536,816）。
- 关闭按钮 `#C42B1C` 悬停，最小化/最大化按钮灰色悬停。
- 边框缩放由 Avalonia 的 Windows 后端处理（拖拽窗口边缘）。

```bash
grep -ri "webview\|cefsharp\|webview2" src/ --include=*.cs --include=*.csproj --include=*.axaml

```
