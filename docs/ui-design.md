# 界面设计

## 设计目标

- 参照 PCL2 的**顶部导航栏**结构（不是侧边栏），黑白极简主题。
- 不做 Minecraft 元素（草方块、草绿、像素网格已移除）。
- 不使用 WebView / HTML / CSS。
- 窗口无系统边框，标题栏完全自绘。

## 字体

- 全局：**SF Pro Display**（从 [SFWindows](https://github.com/bradleyhodges/SFWindows) 获取的 Apple 字体），中文回退 `Microsoft YaHei UI`。
- 首页右上角 "Today" 为 SF Pro Display SemiBold 34px。

> ⚠️ 许可提醒：SF Pro 的 Apple 许可仅允许在 Apple 平台使用。本项目将其用于 Windows 仅作**本地测试**，未随仓库分发字体文件；若要公开发布，请替换为 [Inter](https://rsms.me/inter/)（SIL OFL）等开源字体。

## 窗口行为

- `SystemDecorations="None"`，标题栏自绘：拖动、双击最大化、最小化/最大化/关闭。
- 最大化由 Avalonia 处理工作区，不覆盖任务栏。
- 边缘缩放由 Avalonia 的 Windows 后端处理。

## 用户协议

首次启动显示《用户协议与免责声明》模态窗口：

- 逐条列出软件性质、不提供游戏内容、账号凭据、第三方服务、免责声明、禁止行为、协议变更。
- 「同意并继续」写入 `config/consent.json`，下次不再提示。
- 「不同意并退出」立即关闭程序，不创建任何游戏文件。

## 更新公告

- 设置页填写 GitHub 仓库（`owner/repo`）。
- 启动时请求 `https://api.github.com/repos/{repo}/releases/latest`，读取 `tag_name` / `name` / `body` / `published_at` / `html_url`。
- 结果显示在首页 Today 下方；有更新时显示「查看新版本」按钮。
- 结果缓存到 `cache/update-cache.json`，断网时显示上次结果。
- 版本比较支持 `v1.2.3` 与 `1.2.3` 格式。
