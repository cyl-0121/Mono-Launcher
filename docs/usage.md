# 使用指南

## 一、启动

两种方式任选：

1. **直接运行单文件版**：双击 `publish/win-x64/GlassCraft.exe`（无需安装 .NET）。
2. **从压缩包**：解压 `publish/GlassCraft-win-x64.zip`，双击里面的 `GlassCraft.exe`。

首次启动会在 `%APPDATA%\GlassCraft` 创建数据目录。界面为简体中文、暗色主题。

> 如果 Windows 安全软件（如火绒）弹窗询问是否允许联网，请选择允许，否则版本清单和下载会失败。

---

## 二、三步装好一个能玩的版本

### 第 1 步：下载游戏

1. 左侧导航点「**下载**」。
2. 在上方搜索框输入版本号（如 `1.21.1`），或直接点列表里的版本。
3. 右侧「Mod Loader」保持「原版」，点「**下载并安装**」。
4. 等待进度条走完（Client JAR + Libraries + 4000 多个资源文件，约 3–8 分钟，取决于网络）。

安装完成后，版本会标记为「已安装」。

### 第 2 步：创建实例

1. 左侧导航点「**版本列表**」。
2. 在「选择已安装版本」下拉框里选 `1.21.1`。
3. 实例名称可留空（自动生成），点「**新建**」。

每个实例有独立的 `minecraft` 目录，存档、Mod、配置互不影响。

### 第 3 步：启动

选中实例，点右上角「**启动**」。

- 首次启动需要 Java 21。启动器会自动检测系统 Java；找不到时会在首页提示。
- 启动后下方「游戏日志」会实时显示输出。
- 退出游戏后状态变为「已退出」；异常退出会显示退出码，并自动查找 `crash-reports` 里的崩溃报告。
- 「结束进程」可强制关闭游戏。

---

## 三、安装 NeoForge

1. 「游戏下载」里选中 `1.21.1`。
2. 「Mod Loader」选「**NeoForge**」，下方会出现版本下拉框（默认「最新」）。
3. 点「**下载并安装**」。

安装器会自动处理镜像、依赖和版本元数据。完成后会生成 `neoforge-21.1.1` 版本，在「实例管理」里选它新建实例即可。

> 说明：官方 NeoForge Maven 在部分网络不可达，启动器会自动改用 BMCLAPI 镜像下载。这不是破解，只是换下载源；安装器仍是官方二进制，文件仍做 SHA-1 校验。

---

## 四、Mod 管理

1. 「**Mod 管理**」页，先在下拉框选择实例。
2. 左侧显示该实例 `mods` 目录里已安装的 Mod（自动识别 Fabric / Quilt / NeoForge / Forge 元数据）。
3. 「启停」把文件重命名为 `.disabled`（可逆）；「删除」移入回收站，不直接删除。
4. 右侧搜索 Modrinth：输入关键词 → 搜索 → 选中结果 → 「安装所选 Mod」。会自动按实例的游戏版本和 Loader 过滤，下载后校验 SHA-1。

---

## 五、导入已有实例

「实例管理」页底部：

1. 点「**扫描**」，自动查找本机 `%APPDATA%\.minecraft`、PCL2、HMCL、Prism Launcher 的实例。
2. 在列表里选中一个。
3. 点「**导入所选**」。

导入会**复制**存档、Mod、配置到新的独立实例，**不会修改或删除**源目录。同名文件不会覆盖。

---

## 六、联机

左侧点「**联机**」。有三种方式：

### 1. 陶瓦联机（推荐，跨网络）

基于 [Terracotta](https://github.com/burningtnt/Terracotta)（AGPL-3.0）的点对点联机，不需要公网 IP、不需要端口映射。

**创建房间：**

1. 点「**启动陶瓦**」——首次会下载约 8 MB 的组件到 `%APPDATA%\GlassCraft\data\tools\terracotta`。
2. 进游戏存档，按 Esc →「对局域网开放」。
3. 回到启动器点「**创建房间**」，等待状态变成「房间已就绪」。
4. 把**房间码**发给好友。

**加入房间：**

1. 点「**启动陶瓦**」。
2. 在「输入房间码加入」里粘贴好友给的房间码，点「**加入房间**」。
3. 状态变成「已加入房间」后，点「**用当前实例直连**」，启动器会启动游戏并直接进入。

> 陶瓦的二进制不随启动器分发，首次使用时从 GitHub / Gitee 下载官方原版；启动器只通过它的本地 HTTP API 驱动，未修改其二进制。

### 2. 局域网扫描（同一网络）

1. 对方在游戏里按 Esc →「对局域网开放」。
2. 你点「**扫描**」，等 3 秒。
3. 列表里出现房间后，选中并点「加入」。

### 3. 直连已知地址

1. 选择实例，填 `地址:端口`（如 `192.168.1.10:25565`）。
2. 点「启动并连接」。

## 七、AI Agent

1. 左侧点「**AI 助手**」。
2. 想先体验：提供商选「**演示模式（无需 Key）**」，直接输入问题发送，会看到流式回复。
3. 想接真实模型：
   - 选提供商（DeepSeek / OpenAI / Anthropic / Gemini / Ollama / 智谱 / 通义 / Kimi 等）；
   - 填模型名；
   - 填 API Key（加密保存在本机 DPAPI，不会进日志）；
   - 点「保存配置」，然后对话。

Agent 能调用真实工具：列实例、查状态、安装版本、启动实例、读日志、搜 Modrinth。**安装、启动、删除这类高风险操作会弹窗让你确认，拒绝后不会重试。**

自定义 OpenAI 兼容端点：选「自定义 OpenAI 兼容端点」，填 Base URL（到 `/v1` 为止）、模型名、Key。详见 [agent-providers.md](agent-providers.md)。

---

## 七、设置

- **Java 与内存**：指定 Java 路径（留空自动检测）、最小/最大内存。
- **下载与网络**：并发数、代理、是否启用 BMCLAPI 备用镜像。
- **可视化与动画**：过渡动画、指针光照、低帧自动降档。
- **AI**：流式刷新间隔。
- 首页的「性能档位」可即时切换：高性能 / 均衡 / 低功耗 / 关闭。

---

## 八、日志与排错

- 「**日志**」页显示结构化日志（时间 / 级别 / 分类 / 内容），可复制最近 200 条。
- 游戏日志在 `%APPDATA%\GlassCraft\logs\game-*.log`。
- 应用日志在 `%APPDATA%\GlassCraft\logs\app-*.log`。
- 崩溃报告在实例目录的 `minecraft/crash-reports/`。

常见问题：

| 现象 | 处理 |
|---|---|
| 版本列表空白 / 下载失败 | 检查安全软件是否拦截联网；设置里可开启 BMCLAPI 镜像 |
| 启动提示找不到 Java | 安装 Java 21（Adoptium / Microsoft OpenJDK），或在设置里指定路径 |
| 启动提示文件缺失 | 重新执行一次「下载并安装」，断点续传会补齐 |
| NeoForge 启动报模块冲突 | 该问题已修复；若仍出现，确认实例使用的是 `neoforge-*` 版本而不是原版 |
| 导入后没有存档 | 源目录本身没有 `saves`，或存档在别的路径 |

## 九、数据目录与卸载

所有数据都在 `%APPDATA%\GlassCraft`：

```
config/     设置、DPAPI 加密的账户与 API Key
data/       版本、库、资源、实例、下载缓存
logs/       日志
```

卸载：删除 `publish` 目录即可；如需彻底清理，再删除 `%APPDATA%\GlassCraft`（**会删除存档，请先备份**）。

实例不会自动删除：删除实例时移入 `data/trash/`，可手动恢复。
