# 性能档位对照

GlassCraft 的性能设置是全局策略，同时影响**渲染**与**AI/下载**：

- 视觉档位：高性能 / 均衡 / 低功耗 / 关闭
- 动画与指针光照开关
- 自动降档（帧率持续低于阈值）
- 下载并发数
- AI 流式刷新间隔
- 本地模型 GPU 层数 / 上下文 / 线程 / 批大小

设置保存在 `%APPDATA%\GlassCraft\config\settings.json`，与实例配置分离；除渲染管线重建外无需重启。

---

## 界面效果档位

> 说明：早期版本的 Liquid Glass 渲染管线已按需求移除，当前是 Minecraft 风格扁平界面。
> 档位只影响卡片的阴影/高光绘制，不影响游戏内性能。

| 档位 | 渲染内容 | 相对开销 | 适用场景 |
|---|---|---|---|
| **完整** | 卡片阴影 + 顶部高光 | 极低 | 默认观感最好 |
| **标准**（默认） | 卡片阴影 | 极低 | 大多数设备 |
| **简洁** | 仅填充与 1px 边框 | 可忽略 | 远程桌面 / 老旧核显 |
| **关闭** | 不绘制卡片背景 | 可忽略 | 故障排查 |

实测数据（AMD Radeon 核显，1536×864 @125%）：

- 标准档：首页 38–43 FPS，版本页 39 FPS，实例页 40 FPS，联机页 48 FPS
- 完整 / 简洁 / 关闭档未逐档量化（帧率主要由窗口大小与列表滚动决定）

---

## 自动降级

- `AutoDegrade` 维护一个 10 样本滑动窗口；平均帧率连续低于阈值（默认 32 FPS）时：
  1. 在日志记录降级事件；
  2. 自动切换到下一档（高 → 均衡 → 低 → 关）；
  3. 20 秒冷却，避免抖动。
- 设置页可关闭自动降档。
- 降级事件可在「日志」页查看。

---

## 下载并发

- 默认 8，可调 1–32。
- 同时刻只有一个安装任务；资源对象（约 4000 个）按有界并发下载。
- 实测：4036 个资源对象在 8 并发下约 3–5 分钟完成（受 CDN 影响）。

---

## AI 负载

| 设置 | 说明 | 默认 |
|---|---|---|
| 流式刷新间隔 | UI 增量刷新的最小间隔（ms） | 40 |
| 云端并发 | 预留（当前 UI 单会话） | 2 |
| 本地 GPU 层数 | LLamaSharp `GpuLayerCount` | 0（纯 CPU） |
| 本地上下文 | `ContextSize` | 4096 |
| 本地线程 | `Threads`，0 = 自动（CPU/2） | 0 |
| 本地批大小 | `BatchSize` | 512 |

本地模型加载在后台线程进行，UI 显示 `LocalModelStatus`，不阻塞启动。
