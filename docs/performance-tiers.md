# 性能档位对照

GlassCraft 的性能设置是全局策略，同时影响**渲染**与**AI/下载**：

- 视觉档位：高性能 / 均衡 / 低功耗 / 关闭
- 动画与指针光照开关
- 自动降档（帧率持续低于阈值）
- 下载并发数
- AI 流式刷新间隔
- 本地模型 GPU 层数 / 上下文 / 线程 / 批大小

设置保存在 `%APPDATA%\GlassCraft\config\settings.json`，与实例配置分离；除渲染管线重建外无需重启。

---

## 视觉档位

| 档位 | 渲染内容 | 相对开销 | 适用硬件 |
|---|---|---|---|
| **高性能** | 预模糊背景 + 实时 `CreateBlur(10)` + 折射 + 高光 + 指针光 | 最高（GPU 模糊）。集成显卡约 25–35 FPS | 独显 / 高性能核显 |
| **均衡**（默认） | 预模糊背景 + 实时 `CreateBlur(4)` + 折射 + 高光 + 指针光 | 中。实测 37–56 FPS | 大多数设备 |
| **低功耗** | 原图半透明（无实时模糊），保留边缘高光 | 低。预计 60 FPS | 老旧核显 / 远程桌面 |
| **关闭** | 纯色半透明填充 | 可忽略 | 极低配 / 故障排查 |

实测数据（AMD Radeon 核显，1536×864 @125%）：

- 均衡档首页 37–45 FPS，实例页 37–56 FPS，发布版 44 FPS
- 高性能 / 低功耗 / 关闭档的精确帧率**未逐档量化**（路线图项：一键基准）

## 自动降级

- `AutoDegrade` 维护一个 10 样本滑动窗口；平均帧率连续低于阈值（默认 32 FPS）时：
  1. 在日志记录降级事件；
  2. 自动切换到下一档（高 → 均衡 → 低 → 关）；
  3. 20 秒冷却，避免抖动。
- 设置页可关闭自动降档。
- 降级事件可在「日志」页查看。

---

## 下载并发

- 默认 8，可调 1–32。
- 同时刻只有一个安装任务；资源对象（约 4000 个）按有界并发下载。
- 实测：4036 个资源对象在 8 并发下约 3–5 分钟完成（受 CDN 影响）。

---

## AI 负载

| 设置 | 说明 | 默认 |
|---|---|---|
| 流式刷新间隔 | UI 增量刷新的最小间隔（ms） | 40 |
| 云端并发 | 预留（当前 UI 单会话） | 2 |
| 本地 GPU 层数 | LLamaSharp `GpuLayerCount` | 0（纯 CPU） |
| 本地上下文 | `ContextSize` | 4096 |
| 本地线程 | `Threads`，0 = 自动（CPU/2） | 0 |
| 本地批大小 | `BatchSize` | 512 |

本地模型加载在后台线程进行，UI 显示 `LocalModelStatus`，不阻塞启动。
